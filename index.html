数据 / 团体共用

本地优先存储，可一键导出共享，也可接入 Supabase 实现团队实时同步。

方式一 · 导出 / 导入 JSON（文件共享）

把整本书库导出为一个 .json 文件，发给同事或存到共享网盘；对方「导入」即可合并到自己的书库。无需服务器，最稳妥的团体共用方式。

方式二 · Supabase 实时团队同步（可选）

若你们有 Supabase 项目，开启后所有成员访问同一张表即可实时共享书库。未配置时完全离线使用，不受影响。

  1. 新建 Supabase 项目 → 在 SQL 编辑器执行建表语句（见下方）。
  2. 在 Project Settings 找到 Project URL 与 anon public key。
  3. 填入下方并「启用同步」，之后保存的笔记会自动上传 / 拉取。
CREATE TABLE reading_notes (
  id text primary key,
  payload jsonb not null,
  updated_at timestamptz default now()
);
-- 建议开启 Row Level Security 并按团队邮箱授权

存储说明

当前书库保存于本机浏览器（localStorage 键 reading_notes_v1）。换设备 / 清缓存会丢失，重要笔记请定期「导出」备份。
